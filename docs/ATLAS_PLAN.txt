EXTRACTION CONTRACT — WHAT A SCIENTIST SHOULD READ
Each record starts by explaining:
  What the assay measures, from what input or biological unit;
  how its experimental strategy makes that quantity/association observable;
  which implementation is represented and what limitations qualify it.
For now these sentences live in the EXISTING scope field, with source support in
method_scopes. They precede scope exclusions. This is a prompt/schema-description
improvement, not a new machine-validated measurement ontology. If later retrieval
needs separate measurement/principle fields, introduce a reviewed version change;
do not silently reinterpret old JSON or manufacture those fields from memory.

Example explanatory opening, not a newly model-reviewed extraction:
G&T-seq obtains genomic DNA and transcript measurements from the same individual
cell by physically separating its RNA and DNA and processing them independently.
The depicted implementation uses Smart-seq2 for RNA and MDA for DNA.
Source: https://www.illumina.com/science/sequencing-method-explorer/kits-and-arrays/g-t-seq.html

The agent writes structured JSON with natural-language values. Python generates
the readable workflow.txt and graph from those SAME records. There are not two
independently authored protocols that can silently disagree.

State: what preparation, retained fraction or data exists at an interface.
  label: actual material/data, not the biological target if it is a surrogate.
  kind: material or data.
  properties: supported facts with exact subject, property/value and evidence.
    Existing types cover identity, ends, modification, sequence segments,
    association, physical context, attribution and data content, among others.
    Use only consequential supported properties, not every possible slot.
  components: optional addressable constituents within one preparation.
    Multiple molecular species do not automatically mean separate fractions.
Operation: the action or grouped procedure on exact input/output State IDs.
  label/description: action and what changes; mechanism when supported.
  input_roles/effects: local substrate/primer/reporter roles and supported changes
    to material, location or information; preserve subjects and source support.
  resolution/output_grouping: source block versus supported decomposition and
    whether outputs are separate routes. Shared action names do not prove pooling.
Flow: an explicit directed connection, with evidence:
  State -> Operation = material_input or data_input
  Operation -> State = material_output or data_output
  Operation -> Operation = precedes (ordering, not asserted material transfer)

Card prose and matching guide prose can supply an Operation absent from a
compressed drawing. Record it as text-supported, not depicted. Do not import a
separate variant or full laboratory recipe merely because a paper mentions it.

WHEN TO LOOK DEEPER
A detail is needed when resolving it can change at least one of:
  the actual measurement/readout interpretation;
  the transformation or compatibility of adjacent States/Operations;
  the routing or cell/molecule/location/time association;
  the particular historical difference being claimed.
Routine quantities, buffers or washes are not automatically required. A buffer
becomes relevant if evidence makes it decisive for one of these questions.
Use registered primary evidence to clarify or correct that exact issue. Record
original depiction and correction separately. Missing required evidence triggers
specific acquisition/review; rewriting against the same bundle cannot supply it.
No full-paper requirement for a plainly supported catalogue-level statement.

HISTORICAL CONNECTION CONTRACT
Start from the later implementation's paper and its attribution contexts. Identify
what a reference contributes; verify that contribution in the earlier work. Look
up the referenced method in the reviewed method inventory before creating a node.
Missing methods can become explicitly unextracted contributor entries; never
invent a full workflow from a citation. Publication dates constrain direction but
do not establish influence. Citation presence and resemblance alone are insufficient.

Two historical types, already defined in illumina/relationships.py:
  method_development: an earlier assay arrangement is a documented starting point
    and the later work revises that arrangement.
  component_adoption: an identifiable contribution is demonstrably used/adapted;
    inheritance is limited to that contribution, not the whole prior assay.
Comparison, mechanistic precedent and shared mechanism/purpose are separate layers.
Technical change categories can be clustered later from reviewed descriptions.

Every change account must make this understandable in natural language:
  compared feature; earlier arrangement; later arrangement; retained parts;
  limitation/rationale; demonstrated consequence with comparator/context when
  available; trade-offs or transfer unknowns; evidence from both works.
No demonstrated gain is required to record real adoption. Do not invent a benefit.
The paired workflow overlay locates the change on exact records/interfaces.
The current citation nomination contract still anchors affected Operations;
State/interface distinctions must survive paired localization. This is not a
claim that the current system supports arbitrary unanchored State-only ancestry.
A fresh reviewer must be able to follow the described before-to-after transition.
Only refine a coarse block when the proposed connection actually requires it.

IDEATION CONTRACT
Coordinator: turn the requested capability into distinct research/design mandates
and identify the comparator/improvement question. It does not declare novelty.
Designers: query atlas workflows/changes, search beyond the atlas, propose graphs
using the same material/action/flow meanings and explain the proposed difference.
Literature investigator: search closest implementations, primitive properties and
contrary evidence. Chemistry/interface and measurement/benefit reviewers challenge
physical feasibility and whether the proposed gain survives losses/confounding.
Independent final review accounts for objections after the bounded revision.
Chemistry is a major place to investigate, not a rule that all innovation must be
new chemistry. Routing, capture, attribution, readout and combinations of changes
can matter. A new node or new name is not evidence of an advance. A proposed
transfer stays a hypothesis even when the required primitive property has precedent.
Nothing in this contract establishes experimental success or exhaustive novelty.
