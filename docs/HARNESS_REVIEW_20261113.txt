Workstream 2: evolutionary evidence and focused reading
Read experiments/history_contract_audit_20261113/AUDIT.txt and FOCUSED_CANDIDATE.txt.
Use a specific compared feature, its earlier and later arrangements, attribution
evidence, and optional supported consequences. A baseline/comparator names the
condition tested against; a metric names the measured quantity. A historical edge
needs neither a forced numerical benefit nor a fictitious comparator. Whole-assay
results cannot be assigned causally to every component change.
The focused candidate preserves original source text and offsets, exposes compact
navigation, records questions and delivered context, and retains broader-reading
escalation. Existing scientific checks still apply. Default full-reading behavior
and archived runs stay unchanged. Known-answer retrieval controls cover29/29
selected evidence duties; this measures delivery, not discovery completeness or
scientific accuracy. New native review pilots must use pinned complete analyses.
Method-level design moves without a supported donor still need their own structured
review coverage; inventing a parent to fill an edge is incorrect.

Workstream 3: technologies and source organization
Read experiments/method_intake_audit_20261113/README.txt and LIVE_PILOT.txt.
Screen authoritative title/abstract records before acquiring full papers. Keep
assay-level contribution, component-only work, application, review, software and
uncertain cases explicit. A reagent-centered paper may still demonstrate an
assay-level improvement: record the contribution, then decide whether it warrants
a distinct method/version or only a source update. An abstract-positive decision
is a candidate, never automatic admission or a declaration of global novelty.
Check existing names, publications and implementation scopes before scheduling.
One method can have several depictions and papers; one paper can describe several
methods. Preserve primary/protocol/supplement/component source roles and the
original Illumina classification separately from new curator-proposed placement.
Paper-mode extraction already uses the same scientific schema as diagram mode.
Worked examples guide representation and granularity; target claims need their
own evidence. Missing diagrams do not require a second incompatible schema.
