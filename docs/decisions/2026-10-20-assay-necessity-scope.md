# Select assay requirements rather than reconstruct the original study

The reference benchmark describes the declared general published assay protocol. A source-supported fact becomes an obligation only when needed to execute or understand an assay operation, material/data handoff, attribution or measurement decoding, or to distinguish a consequential alternative. The annotator and independent reviewer must both apply a counterfactual inclusion test: if the detail changes while those assay properties remain intact, does execution or interpretation of the declared assay change?

`why_needed` must identify the actual transformation, interface or measurement consequence. A generic claim that any handling detail could affect yield is insufficient. Original cohort size, replicate count, collection campaign and ethics/consent facts ordinarily remain study context. Per-specimen/per-library origins and logical label lineage remain necessary when consequential; that does not automatically require the original study's particular sample-to-index/run assignments. Read/barcode structures can be assay defining. Pulse/chase intervals that encode molecular age and biological perturbations that define readout remain eligible; this rule does not exclude all timings or biology.

The same necessity test applies to `ReferenceUnknown.consequence`. A missing recipe, historical vendor version or label encoding interface can limit the declared assay. An arbitrary unreported study detail need not become a graph gap. A mixed question must be split so the consequential assay unknown is retained and incidental study reconstruction is excluded. Versioned uncertainty accounting must not force an irrelevant reference question into graph structure; a graph reviewer can request evidence-backed reference revision.

The observed trigger was an ATAC reference candidate that promoted true source-supported sampling/collection/ethics context into a required assay obligation and bundled historical assignment bookkeeping with an assay-important read-structure unknown. This was an inclusion/scope defect, not a finding that those source facts were hallucinated. Historical candidate artifacts remain unchanged. New role prompts apply the rule across all cases, without fixed obligation/node quotas or adaptation to the current extraction harness. Optional truths remain unjudged context rather than automatic negative labels.

Later extraction-harness evaluation must use the same assay-necessity reference scope and the same versioned uncertainty criterion. Changing a reference's graph shape does not justify reducing its scientific requirements; source necessity, independently reviewed scope and exact evidence decide inclusion.
