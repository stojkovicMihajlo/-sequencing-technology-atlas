# Correct rejected graph data without changing the scientific target

The first frozen ATAC construction represented all 28 authored requirements but
was correctly rejected for an additional categorical assertion: the source
described a qPCR monitoring aliquot without establishing its eventual physical
recovery or disposal. Coverage of the reference requirements did not certify
every additional graph assertion. The initial run is a diagnostic, not an
accepted reference graph or a blind extraction result.

Add at most one graph data correction followed by a fresh review, independently
of the existing one-reference-correction limit. The correction constructor sees
the exact prior graph, review, assessment, scores and draft. The new reviewer
sees the unchanged packet/reference and corrected graph, without prior reviewer
scores. No source, reference answer, scientific criterion or operation vocabulary
changes during this correction. No method-specific fact is added to the harness.

Archive every completed graph round separately under `graph_rounds/001` and
`graph_rounds/002`. Write canonical graph/review/assessment/scores once from the
selected final round, including failed final rounds for inspection. Record the
repair count and selected round; report first-pass versus corrected results
explicitly. Never overwrite or erase the rejected candidate. Native transport
failure is not an instruction to retry scientific curation indefinitely.

Correctable record defects include an explicit revision request, an uncovered
critical requirement, a missing/partial uncertainty qualification, or an
explicitly unsupported factual-audit assertion. A missing evidence source,
unassessed judgment or reference-revision request is not itself a graph defect
that may be fabricated away. Removing an overclaim or qualifying it as an
unknown is valid only if the fixed scientific requirements remain represented.

An explicit unsupported factual-audit row independently blocks positive graph
export, cross-method case eligibility and full candidate coverage in reporting.
Coverage fractions remain unchanged. Uncertain and unassessed assertions are
not automatically false; declared audit rows do not establish whole-graph
precision. This gate prevents contradictory positive reports when the same
assessment acknowledges an unsupported emitted assertion.

The correction limit is a bounded curation policy, not an optimal reasoning
budget or a benchmark performance result. Future extraction-harness comparisons
must declare equal opportunity for correction and report both first-pass results
and total cost. Construction here still sees reference answers and remains
model-authored/model-reviewed reference curation, pending expert adjudication.
