# Prototype guarantees and source-checked controls

The user needs a demonstrable prototype and general safeguards before another
large extraction. Inputs remain the exact 2025 scSTAMP preprint source packet
and a historical candidate; the target is a general published method description,
not a synthesis proposal or a complete executable SOP. Historical outputs are
preserved. This development pass makes no full-atlas or zero-error claim.

## What the audit identified

Existing validation already enforces unique IDs, typed endpoints, exact I/O,
binding/Flow agreement, single producers, DAG structure and Module coverage. The
latest graph passes those checks. Reimplementing them would not cure semantic
overstatements. A source audit instead found an ambiguous RNA-versus-cDNA product
description and a need to make demonstration scope clearer per library route.
These are source-backed clarification requests, not evidence of an invented dsRNA
reaction. Fourteen unresolved records overlap; missing recipes and conflicting
descriptions do not all become recoverable extraction mistakes.

Ordinary graph reachability can cross alternative library implementations through
a shared Operation. Natural-language conditions cannot be evaluated as Boolean
route predicates. The candidate's qualifications do not make an unguarded path an
experimentally demonstrated route.

## Minimal implementation

1. Preserve the existing extraction schema and host-controlled stages. Make
   product-versus-analyte and demonstrated-versus-proposed scope explicit in the
   shared semantic contract. These are general instructions, not supplied assay
   answers. Semantic correctness remains an empirical question.
2. Inventory exact start/end/isolated States with `audit-boundaries`. Optional
   disposition manifests are bound to the Workflow digest and complete inventory.
   A complete manifest does not prove its prose true or the protocol complete.
3. Add `query-path`, which refuses to activate conditional/alternative/optional
   Flows. It exposes guarded edge IDs and returns `needs_route_selection`; it does
   not infer a globally coherent route or claim other prerequisites are satisfied.
4. Reuse the existing repair mode and fresh field/source review. Historical reader
   findings are not freshly reviewed in this repair-only experiment. No repeated
   source-obligation generation or specialist readers are needed for unchanged
   sources. Exact model, prompts, source bytes and feedback are archived.
5. Reuse the existing two-call grounding runner. Four source-checked paired
   controls cover an unsupported fate, a numerical change, read-identity reversal
   and a deleted partition operation. Keep expected labels outside visible reader
   inputs, retain failures, score support retention and omission detection
   separately, and refuse to count abstention as successful detection.

The actual ambiguous cDNA field was removed from scored controls after independent
audit. The coverage positive received enough source context to support all shown
claims. Neither control origin nor an earlier model approval determines its label.
These are model-authored, source-checked regression controls, not expert gold.

## Reference implementation audit and choices

- [LabOP](https://github.com/Bioprotocols/labop), pinned prior audit
  `2e2bd88150c71a440771fd369f40295dfd622324`, distinguishes object/control flow and
  guarded decision/merge from fork/join. Adopt explicit relation semantics;
  do not import its execution engine or treat a first matching guard as a way to
  resolve uncertain literature. The prior code/paper audit is in
  `provenance/representation_audit_20261021/lab_protocol_systems.json`.
- [WiCE](https://aclanthology.org/2023.emnlp-main.470/) distinguishes support at
  finer claim units. Adopt complete-claim checks and explicit insufficient support;
  do not import general-domain performance as a genomics verifier guarantee.
- [Attribute First, then Generate](https://aclanthology.org/2024.acl-long.182/)
  selects source spans before generation. Preserve exact contextual evidence;
  source-first composition does not prove every generated clause follows from it.
  The existing pinned code audit is recorded in
  `provenance/protocol_grounding_audit_20261020.json`.

No external code is copied. A second adjacent alternative, Autoprotocol's linear
hardware-oriented instruction representation, was rejected in the prior audit:
flattening alternatives and adding missing execution defaults violate our target.

## Release interpretation

Structural checks have exact, testable guarantees conditional on declared inputs.
Control results measure eight local cases, not all unseen failure modes. A fresh
supported review is still a fallible model judgment. The prototype needs source
navigation, explicit uncertainty and reproducible outputs; bulk promotion needs
broader source-checked evaluation and review calibration. No threshold is described
as an established scientific reliability bound.
