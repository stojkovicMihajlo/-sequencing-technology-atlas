Scientific explanation and source commentary — 12 November 2026

Observed problem
The four-method full-harness run 52047726 preserves useful measurement meaning,
but source narration remains in some scientific fields. Its irCLIP reviewer
correctly requested an explanation of elevated-temperature reverse transcription
that existed only in evidence, then requested source-prefaced wording to preserve
its support level. The issue is not solved by deleting 'the paper reports': that
could turn a proposed rationale or possible bias into an established result.
Pseudo-seq passed first review with treatment/control and reporter/inference
distinctions intact. RASL-seq and MAB-seq were still running when this change was
prepared. Historical outputs and the running runtime remain unchanged.

Decision
Keep the full harness and existing schema. Give description, mechanism and
information_effect one shared definition in prompts.py, delivered to author and
reviewer for BOTH diagram-led and paper-only extraction. Previously the paper
path used separate, broader guidance and did not receive this detailed contract.
Description explains what happens; mechanism explains how it works;
information_effect explains what the output lets us identify or distinguish,
its carrier, condition dependence and necessary later inference.

Scientific fields explain the assay directly. Source identity, source comparisons
and extraction decisions remain in Evidence/Correction. Preserve conditionality,
scope and uncertainty alongside the affected claim. Consequential unknowns remain
recorded. Available scientific explanations cannot exist only in quoted evidence.
Review requests identify the affected field and meaning/qualification to retain.
No forbidden-word validator, automatic text replacement, fixed word count,
method-specific reagent instructions, new schema fields or new graph nodes.

Validation
Existing structural, semantic-control, revision and author-reuse tests remain.
A delivery test checks that BOTH roles in BOTH source modes receive exactly one
copy of the shared operation contract, including revision calls. This verifies
wiring, not scientific compliance. Schema descriptions are aligned; schema field
names and types are unchanged. Historical artifacts are not reserialized.

A bounded two-method follow-up uses irCLIP and Pseudo-seq, identical source/card
pins, model gpt-6.1-sol, xhigh, two workers and at most one author revision with
fresh review. Comparison criteria are kept outside agent context. Assess removal
of extraction commentary without loss of uncertainty, named transformations,
measurement carriers, treatment/control distinction, diagram-level structure and
retrievable properties. This is development, not a causal estimate or a general
hallucination-rate claim. Source qualification that affects interpretation must
not be penalized merely because it is longer.

Git and provenance
Commit harness changes with their rationale, tests, experiment plan and launcher.
Record the exact code commit, file hashes, job ID and result paths for each run.
Commit observed results separately; do not relabel a launched experiment as a
demonstrated improvement. Keep raw source/model archives in the recorded artifact
locations and retain their hashes; do not indiscriminately add large downloads,
credentials, unrelated working edits or generated archives to Git.
