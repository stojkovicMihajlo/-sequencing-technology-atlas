Author tools, retrieval and source intake — 13 November 2026

Local contract
The scientific output is one source-scoped assay reconstruction or a supported
same-feature historical comparison. Model judgments select evidence, interpret
molecular transformations, assign identity/readout roles and state uncertainty.
The application owns source registration, indexing, serialization, provenance,
revision routing and publication. Valid JSON, executed Python and reviewer
agreement separately fail to establish scientific correctness.

Observed behavior, not prompt intent
Read experiments/harness_execution_audit_20261113/REPORT.txt and TRAJECTORIES.txt.
319 native logs and6928 commands were audited. Latest ten-paper prototype had14
authors+14reviewers, all direct JSON patches and no custom constructor scripts.
Canonical full-card+retry3 used named constructors in115/146author attempts and
128/145reviewer attempts. These are observational cohorts, not a controlled
causal comparison of coding versus direct output. Pseudo-seq has an observed
condition-specific semantic defect in a builder; identical prose or code reuse
is not inherently false. Spatial and Paired-Tag defects existed before correction;
the second independent reviews exposed misses of the first reviews. Do not claim
those corrections introduced the errors.

Decision
Do not optimize for whether an author used Python. Prefer declared evidence
retrieval and compact source-linked scientific records, with host-owned assembly
where the existing authoring/evidence registry already supports it. Preserve
exploratory computation when needed, but do not make rebuilding serializers a
scientific author's responsibility. The current Codex CLI exposes general coding
tools; instructions alone do not make that a custom-tool-only environment.
No unverified '--no-tools' or feature-flag claim is adopted. Read-only structured
final output is a bounded experiment for abstract decisions, not a claim of
complete filesystem confinement or elimination of all native tools.

Focused reading candidate
Read experiments/history_contract_audit_20261113/AUDIT.txt and focused_reading.py.
The full-paper rule exists in both prompts and validator. Keep archived/full
behavior unchanged. The opt-in candidate associates questions, exact returned
source offsets/hashes, quote-containing blocks and adjacent context with the
existing before/after/inheritance/optional-result fields. Outlines are navigation,
not scientific evidence; figure/table mentions are not inspected figures/tables.
Retain broader reads with explicit reasons, unavailable-source research leads,
independent scientific assessment, and negative controls for distant exceptions.
Known-quote delivery tests are not evidence of complete discovery or better
scientific accuracy. Nomination currently keeps the full seed gate in this
bounded candidate; removing even that needs a separate discovery-coverage test.

New-method intake
Read docs/decisions/2026-11-13-method-intake.txt. Abstract-first screening separates
assay-level contribution, component-only work, applications, software, reviews
and unresolved cases. Positive means a candidate, not a new admitted method.
Identity/alias/version matching precedes scheduling and full-text acquisition.
Keep one method identity with primary/later-protocol/supplement/component roles.
An older unextracted version of a known card is not a missing-card failure.
The source intake pilot uses all supplied authoritative abstracts, constrained
final JSON, host-written artifacts and two blinded independent classifications;
it is not an author/reviewer correction loop or a validated scientific classifier.

Tests and claims
1. Compare unchanged source packets and scientific schemas when testing reading
   or authoring alternatives. Track unsupported claims, missed consequential
   facts, condition/identity mistakes, source access, input/output tokens and time.
2. Judge before/after at the same scientific feature; performance is optional.
   A comparator is the baseline, a metric is what was measured. Neither is
   required to record supported inheritance or an absolute capability.
3. Re-review complete revised artifacts, with a field diff and the old findings.
   A resolved request does not establish that unchanged fields were correct.
4. Paper-mode extraction already uses the same State/Operation/Flow schema as
   diagram mode. Worked examples guide representation, never target biology.
5. No-donor design contributions currently survive mainly as summary prose;
   structured method-level change review is a real remaining gap. Do not invent
   an ancestry edge just to give every design change a source node.
