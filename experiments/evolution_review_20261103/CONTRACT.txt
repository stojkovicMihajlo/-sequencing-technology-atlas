Question fixed before implementation
How can the completed Illumina source workflows support a method-evolution graph
and evidence-grounded design proposals without pretending that citation,
similarity, method identity, and experimental compatibility are the same claim?

Inputs
The pinned 478-record November archive, its later publication decisions, existing
one-hop citation and paired-workflow pilots, and registered primary evidence.
Historical records are immutable. This pass may inspect all stored records but
cannot claim a new independent full-paper scientific review of every assertion.

Output
An exhaustive per-record readiness/field-coverage ledger; a small shared relation
policy used by both existing relationship prompts; tested, evidence-preserving
access to the earlier paired result; and an implementation/evaluation decision.
No new native model calls or bulk extraction are needed for this diagnostic pass.

Scientific object and invariants
An edge is a scoped evidence-backed assertion between specified implementations
or contributions. A citation is a retrieval lead. A shared mechanism is a
correspondence. Only supported adoption/development is historical lineage.
Each claim retains what was retained/changed, the affected operation groups,
two-sided support, context and unresolved issues. A component inside a combined
block must not become inheritance of the whole block. Distinct claims between
the same methods coexist. Disconnected methods remain legitimate.

Alternatives
1. Adopt a paper citation network as evolution: rejects the distinction above.
2. Infer history from semantic similarity or graph edit distance: retrieves
   candidates, but cannot establish direction or actual historical transfer.
3. Follow citation contexts, inspect the cited implementation, anchor the scoped
   contribution to existing workflows, and independently review the claim.
   Use similarity separately to find analogies and additional search leads.

Success / negative controls
Every archived source occurrence appears exactly once with current admission;
no canonical method count is inferred from source count or spelling. No source
graph is edited. A history-only query cannot return a shared-mechanism or
comparison claim. A changed/rejected/stale review, unknown relation, bad anchor,
missing side evidence or wrong direction cannot silently pass publication.
Qualifications and source pointers survive retrieval. Passing these checks does
not establish semantic truth, historical completeness or experimental feasibility.

Downstream scope
A proposed assay is a proposal, with intended capability and one or more explicit
design changes, including changes without an existing parent. Its predicted gain
and interface transfer are hypotheses. It does not enter the historical layer.
No absent graph edge, graph distance or novel name is a novelty certificate.
