Minimal architectural implications from observed execution:
1. Keep source retrieval, artifact construction, scientific assessment and
   publication as distinct stages with immutable candidate/review hashes.
2. Preserve native exploratory code and tools. A builder can help serialize a
   record; neither a builder nor direct JSON authoring establishes semantics.
3. After assembly, inspect the actual final artifact across condition, material,
   operation, readout and visual-brief fields. Independent review must evaluate
   all fields again; checking only requested changes misses older defects.
4. Add an explicit scientific field-diff report to revision review. Distinguish
   introduced, propagated and preexisting findings instead of inferring cause
   from which review first mentioned them.
5. Compare architectures on fixed source packets with semantic outcomes, source
   coverage, author/review cost and consistency. These observational cohorts do
   not isolate prompt, schema, context length or writing-tool causal effects.
