iCLIP -> eCLIP: actual edge audit

Conclusion
The stored C_R6 edge already contains three compared features and actual design changes. A display showing only reused UV capture is sparse relative to the existing data; it is not evidence that the extractor recorded no differences.

1. Capture strategy retained. Both routes use UV crosslinking, partial RNase digestion, target IP, gel/nitrocellulose selection and proteinase recovery. No isolated benefit is established for this unchanged feature.

2. Library route changed. Original iCLIP places inverse adapter regions and a BamHI site in the RT primer, then circularizes and linearizes cDNA before PCR. eCLIP adds an indexed adapter to the RNA 3-prime end on beads, performs RT, then ligates an ssDNA adapter to the cDNA 3-prime end. This retains recovery of crosslink-truncated cDNA and nucleotide-scale endpoints. RNAtag-Seq is separately credited for the sequential construction architecture; not every eCLIP improvement should be assigned to iCLIP.

3. Molecular tag placement and decoding changed. iCLIP's RT primer contains a 3-base random tag plus experiment barcode. eCLIP supplies N5/N10 in the post-RT ssDNA adapter; its deduplication uses both mapped read starts and the random-mer. No isolated performance gain is demonstrated for tag movement/length.

Results and units
The local RBFOX2 comparison used 20 million HEK293T cells and the same antibody. eCT—the cycles required to obtain 100 fmol library under an assumed 100 percent PCR efficiency—was 23.6 for iCLIP versus 13.0/13.3 for eCLIP. The authors interpret this as approximately 1000-fold more adapter-ligated pre-amplification product. It is NOT 1000-fold fewer PCR cycles. At 20 million uniquely mapped reads, usable-read fractions were 30.8 percent and 85.2 percent: 54.4 percentage points difference. These are coordinated whole-assay results, not isolated causal effects of capture reuse, tag movement or one ligation step.

Other eCLIP contributions
The seed also describes omitted radiolabeling, optional on-bead index-enabled pooling, ligation conditions and size-matched input controls. Some appear on C_R7 inheritance or C_R8/C_R15/C_R17 context/comparison records; they should not all be restated as iCLIP inheritances. Hiding context can hide important method-wide design information. The exact R7 chemistry-specific transfer remains appropriately limited by its missing supplement.

Publication weakness and general correction
ChangeAnalysis.summary exists, but old graph_overlay did not publish it on the method node. Source-supported method-level changes without a donor can disappear while ancestry remains. Next exports now retain method_contribution_summary with source metadata and explicit status: model-authored summary, not independently adjudicated structured novelty. Shared prompt/reviewer changes require a contribution-first account and complete same-feature comparisons, without inventing ancestors or causal benefits. This does not add a new structured novelty schema or establish exhaustive method contribution coverage.

Presentation
Lead with all three compared-feature headers, then show before/after/consequences per feature. Keep contributor description as ancestry context rather than the sole transition explanation. Existing artifacts remain unchanged.
