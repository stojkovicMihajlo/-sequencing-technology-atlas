PAPER-ONLY EXTRACTION TRANSFER PILOT

Question: do accepted atlas output examples improve extraction of a newer assay
when no Illumina workflow decomposition is supplied?

Freeze the target paper version and available supplements before either condition.
Use the same declared method scope and source bundle in both conditions. A receives
no worked examples; B receives two complete accepted examples from other methods.
The target schema and scientific/source checks remain the same. Both use fresh
native authors and independent reviewers; reviewers receive neither examples nor
condition. No correction rounds in this first comparison. Source recovery after
an evidence hold would create a new source-version experiment for BOTH conditions.

Report actual outputs,review findings,material/data routing,typed properties,
source support,missing consequential facts,latency and token usage. Operation count
is descriptive,not a quality score. Several faithful decompositions can be correct.
One pair on one paper cannot establish general improvement or freedom from model
memory. Examples must not become evidence for the target. No canonical atlas
admission or evolutionary relationship is inferred by this experiment.
