Historical scientific failures — inspected 8 November 2026

The serious boundary is source entailment: a real quotation can be attached to a
claim that does not follow from it in this condition or at this scope. Structural
validation does not settle that. A separate LLM reviewer can also overstate evidence.

Pseudo-seq: wrong condition
The author saw the mock-control passage before generation. Its construction script
made descriptions conditional on treated/mock input, but assigned the same chemical-
recording explanation to both information_effect fields. The mock field therefore
contradicted its own input and the source. Valid JSON and real quotations passed;
the independent reviewer caught the scientific error. Two fields were corrected,
and a fresh review accepted the changed candidate. The observed construction is
established. The model's internal reason and prompt-level cause are not established.
Python and shared wording are not inherently erroneous; an earlier shared endpoint
statement was valid for both conditions.

ATAC-seq: unreported outcome asserted as fact
The benchmark author wrote that no sequencing library is recovered from the
monitoring branch. The source specifies the aliquot's monitoring role and the
remaining production reaction; it does not establish the aliquot's eventual fate.
This is an unsupported extra assertion, not proof that the opposite happened.
The review withheld this case despite all 28 required facts being covered.
Completeness therefore does not establish precision or justify additional claims.

ATAC-seq: reviewer qualification drift
An earlier reviewer changed qualified wording about no reported material return
into the categorical assertion that the analytical product is not returned. It
marked that target supported. Four other targets in that same review were marked
unsupported, so this is not evidence that the entire graph passed. It does show
that reviewer rationales can introduce stronger claims than their evidence supports.

Do not put every problem in this category
The vague mNET-seq starting label has HeLa cells recorded in a separate property.
That is a readability/organization problem; saying the specimen is entirely absent
would itself misreport the record. Missing sources and invalid source references
also require different remedies from false interpretation of an available source.

What the six new runs establish
All six submitted pre-review artifacts avoided the old definite mock error. Three
refined fields were clearer in isolation than two of the baseline fields. This
supports a small readability observation. It does not establish prevention or the
reviewer's likelihood of catching a deliberately supplied error.

What to measure next
Use the preserved erroneous records and matched corrected records with the same
sources in repeated full-workflow reviews, hiding expected outcomes from reviewers.
Measure errors accepted, correct statements rejected, and qualifications lost in
review rationales. Include correct shared wording and source-supported negatives
so the test does not reward rejecting everything. Prior short-context tests and
one seeded full-workflow test already exist; they must not be portrayed as current
reviewer reliability or a fresh untouched evaluation.

No additional model runs, production prompt changes or atlas changes were made
in this investigation. historical_failure_review.json records exact fields,
source passages, trace locations, file hashes, detection and admission boundaries.
