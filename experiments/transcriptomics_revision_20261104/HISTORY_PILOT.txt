Citation-guided connection pilot — 4 November 2026

Objective: start with the accepted irCLIP workflow and its original full paper;
follow methodological references and return independently reviewed, scoped
historical connections. Do not re-extract the method or force an expected ancestor.

Reuse: experiments/citation_lineage_pilot/{run,models,prompts}.py, the existing
CodexWorker, source acquisition and illumina/relationships.py relation definitions.
No new framework, new agent team or new innovation-change taxonomy.

Order: bibliography/context preparation -> reference nomination (account for all
references) -> retrieve selected primary papers -> analyse -> fresh review ->
at most one analysis/review correction -> separate graph overlay.

Hard checks added to the existing contract:
- A new claim's citation context belongs to the exact referenced publication.
- Workflow claims name actual seed operations. Separate validation experiments
  cannot use those IDs or publish assay-development/component-adoption edges.
- Reviewer acceptance includes literal evidence from both specific papers.
- Missing citation context withholds the connection even if accepted by a model.
- Archived records retain their prior contract; no retroactive upgrade.
Existing checks: exact quotes, source levels, nominated reference identity,
exact workflow IDs, every claim reviewed, every uncertainty assessed, fresh native
sessions, immutable inputs and version-bound artifact hashes.

Scientific review still has to establish reference identity, actual adoption vs
comparison/precedent, before/after change, consequential interfaces, chronology,
and measured gain vs explanation. These are not guaranteed by string validation.
No invented before-side workflow or automatic catalogue identity merge. A diagram
operation can contain a smaller adopted component; the claim must say which part.
If exact location requires unextracted detail, record that need rather than edit
the source graph. Multiple contributors/changes and zero historical links allowed.

Historical layer: method_development (assay architecture) and component_adoption
(specified procedure/component). Precedent/comparison layers are not descent.
Key change is descriptive, not forced into a preconceived innovation taxonomy.

Inspection plan: review the reference nomination coverage, selected sources and
content levels, every positive historical claim and withheld reason, exact
operation location, citations used by independent review, runtime/usage. Query
history separately from comparisons. Selective source retrieval still cannot
recover every DOI/publisher-only paper. Full chronology/preprint discovery and
canonical earlier-method workflow binding are not implemented in this pilot.

Success means an auditable bounded result with defensible accepted/withheld
claims, not a required number of edges or agreement with a hidden answer. Prior
Drop-seq run revealed outside-workflow ddPCR adoption, motivating scope separation;
this rule is not irCLIP-specific. These changes are additive to existing audited
citation/context and occurrence-preserving graph design (31 October decision).
