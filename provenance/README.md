# Historical evidence and run records

These files record previous runs, audits, source identities, and validation.
They retain their original paths, content, and timestamps where applicable.
They are not the place to start reading implementation code.

The current Illumina work's existing checkpoint files are in
`experiments/illumina_full_20261031/`: `RESUME.txt`, `CURRENT.json`, and `CHECKLIST.csv`.
They are dated records; remote checkpoints are authoritative for live job status.

Use the main repository README for today's source-code layout. Older commands
inside archived prompts and reports intentionally keep the names that were used
at the time. `docs/maintenance/path-migration.json` maps the corresponding
old development locations to the reorganized source tree.
