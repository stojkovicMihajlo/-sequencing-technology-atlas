Both calls use Sol 6.1 / xhigh, no previous review, no correction, no network/web,
source coverage and factual-field review. Reader-finding review is not available
in `review_only`; neither arm receives a fabricated reader lineage. Calls run
sequentially in a Qiu CPU allocation. Native failures remain results; there is no

The candidate is unchanged. Its existing optional image operation asserts an

Only localized, source-grounded negative judgments count as detection. Generic
rejection does not. Supported-interface retention is scored separately, so
rejecting everything cannot pass. Other negatives require source assessment and
are not automatically called false positives.

The earlier clean reviewers disagreed on this same relationship. Repeating the
baseline controls for that observed variability. A single pair can expose a
regression or failure; even a favorable difference cannot establish a reliable
improvement. No active extraction is edited or supplied this case's corrections.
