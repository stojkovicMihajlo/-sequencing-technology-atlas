Observed before/after differences

Drop-seq
Both records have five Operations, seven States and eleven Flows. Both already
explain RNA hybridization to bead primers, droplet breakage before bulk RT,
barcode-bearing cDNA and paired-read interpretation. These are not newly
discovered facts in the new extraction. The current terminal State reads has a
direct sequence-data label, data_type=sequence_reads and separate cell/molecule
attribution carriers. The old s.readout label mixed the quoted mRNA caption with
the sequencing readout, though its features clarified the distinction.
The current Correction template_switch_handle explicitly addresses addition of
the PCR handle versus the catalogue's replacement wording. The older o.cdna
description already made that correction but did not expose it as a Correction.
Primary b00011 and Figure 2A/b00112 support the primer design and handle addition;
the improvement demonstrated here is accessibility and annotation consistency.

Smart-seq2
Both records have five Operations, eight States and twelve Flows, and preserve
the same principal route and oligo chemistry. The current s_tso records the LNA
residue as property=modification with a specified 3-prime-terminal site; the old
s_tso already describes that chemistry in features. The source is the Illumina
card's explicit TSO description, not an invented interpretation of the original
paper abstract. Molecular components, associations and sequence segments can now
be inspected independently. This does not establish additional scientific recall.

CEL-Seq
Both records already resolve the omitted IVT step and the diagram's misleading
second-strand RNA caption using supplied literature. The current operation labels
say second-strand cDNA synthesis directly; the old labels retained the caption
while the Corrections explained it. The current graph distinguishes sequencing
from barcode demultiplexing and records paired-read roles in a Correction. It
uses twelve Operations versus fourteen in the baseline; count is not a quality
metric. Scope limitation remains: the original paper is abstract-only in these
bundles. Detailed ds-cDNA/pooling/IVT support comes from an experimental comparison
paper's Methods, explicitly described as following the earlier CEL-seq protocol.
That supports the displayed distinction but does not verify all original-version
details or warrant treating the comparison implementation as interchangeable.

MARS-Seq
The latest preserved baseline already records unresolved tag layout, fragment
retention and strand interpretation. The new reviewer additionally holds the
DNA-to-RNA interface pending the original supplementary methods; the current
writer uses an unresolved interface instead of asserting primary verification.
This shows that the missing-evidence gate works in this case, not that accuracy
has automatically improved. Whether every held item is necessary at the chosen
Illumina architecture scope needs adjudication. Primary verification of an exact
historical change can require more than a source-qualified schematic extraction.
SOURCE_RECOVERY-001 remains unfixed; the requested supplement cannot be obtained
by the correction loop itself.

General limitations to carry into final evaluation
1. The source bundles changed. Combining three depictions supplies additional
   context, so any improvement cannot be credited solely to the prompt/schema.
2. Merging depiction registries repeats identical document content under distinct
   source IDs. Drop-seq has 68 registered entries but 39 unique kind/access-level/
   content fingerprints; Smart-seq2 90/50; CEL-Seq 101/54; MARS-Seq 48/27. These
   duplicates are not independent corroborating papers. Future deduplication
   should preserve each depiction association and all original provenance.
3. More review checks primarily reflect more separately represented properties.
   Acceptance counts and fewer unknowns are not accuracy metrics.
4. Consistent source sufficiency at a declared scope, cross-method alignment and
   reviewed historical relationships are not established by these four records.

Judgment
Useful pilot workflow representations with an observable improvement in typed,
inspectable annotation. Much of the core science was already present in the older
records. Await the scheduled source-grounded A/B comparison and historical pair
review before claiming broader improvement or readiness across all methods.
