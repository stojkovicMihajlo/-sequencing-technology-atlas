# Source preparation and retrieval

- `retrieval.py` provides literature discovery interfaces.
- `acquisition/` retrieves and checks document identities, formats, and supplements.
- `inventory.py` accounts for methods in the earlier atlas.
- `packets.py` prepares and reads source passages for detailed protocol extraction.
- `document_manifest.py`, `jats_text.py`, and `cached_documents.py` inspect/render sources.
- `originals.py`, `derivations.py`, and `relocation.py` retain source provenance.
- `worklist.py`, `search.py`, and `evidence_views.py` expose bounded evidence navigation.
- `prepared_sources.py` supports source preparation in the earlier profile pipeline.

The Illumina-specific catalogue/diagram inventory is `../illumina/sources.py`.
